# Roadmap — ParaBank Automation Framework

Spec: `docs/superpowers/specs/2026-11-21-parabank-automation-design.md`

The work is split into plans that each end with working, tested software and updated docs.
Each later plan is written in full detail only after the previous one is done, so it can
reference the real code that exists by then.

| Plan | Delivers | Spec items | Docs added |
|---|---|---|---|
| **01 Foundation & core library** | Maven multi-module skeleton; `automation-core`: ConfigReader, ExcelUtil, TestDataGenerator, DriverFactory/DriverManager, Locator, UiDriver, SeleniumUiDriver — all unit-tested | E1, E2 (base), E7 (pom setup), F1 (reader) | README, DECISIONS, INTERVIEW_QA, guide 01–05 |
| **02 Registration & login** | Page objects, Cucumber+TestNG runner, hooks (driver per scenario, screenshots), Excel workbook, register 10 users with write-back (relative locator for Last Name), `ConcurrentHashMap` user registry, login positive/negative, `@knownDefect`, footer link in new tab + window-handle `Set`, Log4j2, Extent with Base64 screenshots | F1–F6, F11, F12, E8, E9 | guide 06–08 (BDD, POM, parallel, Collections, Selenium 4) |
| **03 Transfers + Rest Assured hybrid** | `ApiClient`/`ParaBankApi`, idempotent registration check via API, open account, Transfer Funds, Bill Pay A→B, `ArrayDeque` transfer queue, account-number `Set`, Actions API hover/scroll on Accounts Overview, API balance verification | F3, F7–F9, F11, F12 | guide 09–10 (API layer, hybrid testing) |
| **04 Retry engine & reports** | RetryOrchestrator (threshold, cumulative %, browser rotation, rerun file), Extent + Cucumber HTML per run, combined report | E3, E5 | guide 11–12 |
| **05 Jenkins & JFrog** | Local Jenkins (Homebrew), Jenkinsfile, JFrog free cloud publish of `automation-core`, consuming it from Artifactory, Jenkins CSP for Extent | E6, E7 | guide 13–14 |
| **06 (Phase 2) API suite** | Rest Assured features for all major endpoints + JSON schema validation | F10 | guide 15 |
| **07 (Phase 2) Playwright engine** | `PlaywrightUiDriver`, Run 3 on headless Playwright via config | E4 | guide 16 |

Interview Q&A (`docs/INTERVIEW_QA.md`) grows with every plan: each component gets
"how it works", "why this way", and "what if the scenario changes…" questions.
